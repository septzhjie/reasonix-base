## Reasonix 的飞书连接模式

Reasonix 的飞书 adapter **支持两种模式**,通过 `[bot.feishu]` 的 `mode` 字段切换:

| 模式 | 说明 | 需要公网? |
|---|---|---|
| `webhook`(你当前用的) | 飞书平台把事件 **POST 到** 你的 `:8080/feishu/event`,需 `verification_token` 验签 | ✅ 需要(订阅 URL 公网可达,即你之前入站不通的根因) |
| `websocket`(长连接) | bot **主动向飞书服务器建立长连接**(官方 SDK `larksuite/oapi-sdk-go/v3/ws`,支持自动重连),事件由飞书推送过来 | ❌ **不需要**,内网也能用 |

源码证据(`internal/bot/feishu/feishu.go`):
- `switch mode { case "webhook": ...runWebhook; default: ...runWebSocket }` —— 设 `mode = "websocket"` 即走长连接
